# SARIMA
 
## Components
We split the date to seasonal and  non-seasonal components.
SARIMA(p, d, q)(P,D,Q)m
p, d, q - non-seasonal component. see [[ARIMA]]
P, D, Q - seasonal component

### seasonal component
P - seasonal autoregressive order
D - seasonal differencing order
Q - seasonal moving average order
m - number of periods in each season
